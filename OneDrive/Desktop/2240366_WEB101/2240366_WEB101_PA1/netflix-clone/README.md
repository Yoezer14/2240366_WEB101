# Netflix Clone using React

## Project Description
This project is a Netflix-inspired homepage created using React and Vite. The application demonstrates component-based architecture, reusable UI components, and responsive design principles.

---

## Features
- Responsive Netflix-style UI
- Reusable React components
- Dynamic movie cards using props
- Mobile, tablet, and desktop support

---

## Technologies Used
- React.js
- Vite
- CSS

---

## Component Structure

App
├── Navbar
├── Hero
├── MovieRow
│ └── MovieCard
└── Footer

---

## How to Run Project

1. Install dependencies

npm install

2. Start development server

npm run dev

---

## Functionality
The application recreates a Netflix homepage interface where users can view movie sections and responsive layouts across multiple screen sizes.
